# Submission images

Three files for the competition form. `icon.png` is the app mark at 512 by 512: the hunt
orange square on night navy with the Vettai V in Big Shoulders, the same two colours and the
same typeface the app uses, and it stays readable when a phone shrinks it to a tile.
`thumbnail.png` is the 240 by 240 square the form asks for: a crop of the landing hero with
the live city behind the title, shot from the deployed site rather than drawn in a design
tool. `landing.png` is the same hero at 1280 by 720 for the screenshot row, with the live
counters the server was reporting at the time.
