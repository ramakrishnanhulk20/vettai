orange square on night navy with the Vettai V in Big Shoulders, the same two colours and the
same typeface the app uses, and it stays readable when a phone shrinks it to a tile.

running behind the title, taken from the app itself rather than drawn in a design tool, so
the numbers in the corner are the ones the server was reporting at the time.
